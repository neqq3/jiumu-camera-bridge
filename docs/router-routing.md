# 单设备 DNS 与路由方案

适用于研究中的无账号本地绑定，以及账号辅助后的外网隔离。这里是配置设计与检查顺序，**不是已完成的安装教程或可直接导入的路由规则**。截至 2026-10-11，没有通过本项目修改测试家庭的路由配置，也没有完成本地绑定服务真机验证。

## 优先使用单设备 DNS

1. 确认摄像头当前家庭 LAN 的 MAC / IP，给该设备建立或保留静态租约；不要混用摄像头 AP 热点的 BSSID / IP。
2. 如果路由器支持单设备 DHCP 选项，只给摄像头下发本地 DNS；保持其网关、其他租约以及全局 DHCP / DNS 配置不变。
3. 为已核实的厂商引导域名添加精确解析，并将规则作用范围限定到摄像头的单个 IP。禁止空白来源范围、全网段或厂商全部域名的通配重写。
4. 本地服务先准备好正确监听端口与有限日志，再验证摄像头实际发来的查询和连接。HTTP 引导原目标端口为 80，仅改 A 记录不能把该端口自动变成另一个管理端口。
5. 若摄像头忽略 DHCP DNS，不启用全屋强制代理作为补救；改查单设备 DNS 定向转发或隔离实验网是否可用。

爱快官方的 [DNS 文档](https://www.ikuai8.com/support/ymgn/lyym/wlsz/dns.html) 描述了域名、解析地址和作用 IP 段；代理模式是否生效还取决于终端使用的 DNS。本项目已在 3.7.21 x32 免费版页面只读确认单设备 DHCP DNS 字段及作用 IP 段，但尚未验证应用后的效果。不要把其他爱快产品线的界面当作本版本功能。

## 缓存数字 IP 时才考虑定向 NAT

固件可能优先使用缓存服务器 IP，不再执行引导查询。DNS 重写对此未必有效，需要基于本摄像头实际观察到的目标 IP / 端口考虑目的 NAT：

| 匹配项 | 要求 |
| --- | --- |
| 来源 | 摄像头单个固定 LAN IP |
| 入接口 | 已核实的摄像头 LAN 接口 |
| 目标 | 实包确认的服务 IP 与端口，不使用全公网匹配 |
| 协议 | 实际协议，例如绑定 TCP；DNS 的 TCP / UDP 另行处理 |
| 转换地址 | 自有本地服务监听地址，不能误指向路由管理页 |
| 生命周期 | 独立命名、逐条启用、记录原状态和移除方法 |

同一子网内 DNAT 的回复可能绕过路由器，必须核对回程；必要时需要同样限定范围的源 NAT 或独立实验子网。不能仅凭存在 NAT 表单就保证双向连接成功。爱快本产品线的 [NAT 文档](https://m.ikuai8.com/support/ymgn/lyym/wlsz/nat.html) 可作为字段参考，实际能力及回程以对应版本验证为准。

## 外网隔离与本地服务分别验证

DNS 重写不等于断网。要提供本地隐私模式，应针对摄像头阻断到 WAN 的流量，保留到本地桥接、DNS、必要的 DHCP / 时间服务的通信，核对 IPv4 和 IPv6。不能通过关闭全网 IPv6 或修改全局默认策略来代替单设备规则。

厂商共存方式不使用替代绑定服务、不主动更改设备密码，也不启用上述外网封锁。它和本地隐私模式具有不同的数据去向，见 [接入方式](connection-modes.md)。

## 实施与回退边界

部署前准备本地服务、健康检查和停用方式，取得现有配置备份；独立记录实际新增条目，不以恢复整个路由配置作为日常回退。对承载全家网络的主路由，不修改 WAN、默认路由、PVE 网桥或全局 DNS，不通过重启主路由来验证实验。

第一次只测试引导连接和脱敏元数据。收到实际协议包后再验证单台摄像头的设密、独立认证、真实媒体解码及断电冷启动。测试失败时移除本项目新增的单设备规则，恢复该设备原 DHCP 选项；不清空全局 DNS 缓存、不删除其他规则。涉及设备密码变化时另按凭据恢复方案处理，网络回退不代表密码也自动回退。
