## 发行范围

源码候选包含桥接、构建文件、安装说明、研究结论；不包含原厂 APK / `.so` / 固件、反编译输出、私人抓包、真实账号 / 设备标识 / 密码 / Wi-Fi 数据或录像。实验性设密、复位和 BLE 操作脚本尚未纳入用户安装包。

目前在私有仓库内通过 GitHub Actions 构建和验证开发镜像，不变更仓库或镜像的公开可见性。流水线记录实际 FFmpeg 及依赖版本、构建参数与许可文本；对外分发前还需准备对应源码等材料，不能用上游首页链接或短期 CI 日志替代。详见[发布流程](releases.md)。

可采用一个仓库存放全部可发布材料。以后出现多个加载项、独立维护团队或独立版本周期时，再考虑拆分 HA 应用目录仓库。
