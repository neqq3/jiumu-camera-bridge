# 验证记录与后续工作

截至 2026-10-11，以下是单台 A907-J 的有限时长实验，不代表全部型号或长期运行保证。

- 用普通账号密码独立登录、取得设备列表并选择设备；无需读取 APP 缓存。
- 纯 Node.js 桥接在 Linux amd64 Docker 中运行，APP 与旧 Android 桥接停止后仍取得新的音视频。
- Docker 重启后从本地配置恢复，标准 RTSP 连续解码约 12 秒；Frigate 新生成录像包含 H.264 视频与 AAC 音频。
- 2,008 个真实分片回放得到 415 个媒体帧；乱序和重复输入结果一致，另验证序号回绕和非法分片拒绝。
- 未认证 RTSP 返回 401；HA Ingress 模式的 LAN 直连及伪造转发 IP 请求被拒绝。
- 后续 AP 无账号测试：311 个 HLP 数据包重组得到 14 个视频帧和 4 个音频帧，未计入非法或丢弃包；Pillow 解码全部 14 帧 JPEG，均为 640×480。本项没有重新解码音频，也没有验证长时间 AP 运行。
- 取得同版本原厂 OTA 文件并离线解包，通过目录长度 / MD5、RBL CRC、解包长度 / FNV 检查；没有刷机。固件命令分发和认证分析见 [研究记录](research/protocol.md)。
- [本地绑定实验服务](local-binding-service.md) 已实现 HTTP 引导与 TCP 登记、challenge、单次绑定。15 组回环测试覆盖正常流程、来源/身份拒绝、拆包/异常数据、超时、重复与重启、存储故障和清理；不访问摄像头或路由器。另使用已核验固件中的真实协议材料完成模拟客户端往返，核对 8 处固件指针；未执行固件，也未证明真机接受密码。

原始抓包、录像和认证比对数据含隐私，未随仓库提供。因此公众不能只凭本仓库独立复现这些历史真机结论。后续应补充不含私人信息的测试向量及更多型号验证。
