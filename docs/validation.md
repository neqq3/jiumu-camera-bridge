# 验证记录与后续工作

截至 2026-10-11，以下是单台 A907-J 的有限时长实验，不代表全部型号或长期运行保证。

- 用普通账号密码独立登录、取得设备列表并选择设备；无需读取 APP 缓存。
- 纯 Node.js 桥接在 Linux amd64 Docker 中运行，APP 与旧 Android 桥接停止后仍取得新的音视频。
- Docker 重启后从本地配置恢复，标准 RTSP 连续解码约 12 秒；Frigate 新生成录像包含 H.264 视频与 AAC 音频。
- 2,008 个真实分片回放得到 415 个媒体帧；乱序和重复输入结果一致，另验证序号回绕和非法分片拒绝。
- 未认证 RTSP 返回 401；HA Ingress 模式的 LAN 直连及伪造转发 IP 请求被拒绝。
- 后续 AP 无账号测试：311 个 HLP 数据包重组得到 14 个视频帧和 4 个音频帧，未计入非法或丢弃包；Pillow 解码全部 14 帧 JPEG，均为 640×480。本项没有重新解码音频，也没有验证长时间 AP 运行。
- 取得同版本原厂 OTA 文件并离线解包，通过目录长度 / MD5、RBL CRC、解包长度 / FNV 检查；没有刷机。固件命令分发和认证分析见 [研究记录](research/protocol.md)。
- [本地绑定实验服务](local-binding-service.md) 已实现 HTTP 引导与 TCP 登记、challenge、单次绑定。17 组回环测试覆盖正常流程、来源/身份拒绝、拆包/异常数据、超时、重复与重启、存储故障、清理、显式启用的 P2P 初始化，以及摄像头重连时仅由认证通过的新连接替换旧会话；测试本身不访问摄像头或路由器。另使用已核验固件中的真实协议材料完成模拟客户端往返，核对 8 处固件指针。
- HLP 控制确认增加 4 组纯离线测试：单包确认丢失后的累计确认、跨序号回绕、未来/异常游标和错误来源、单包及累计确认混合且不重复计数。依据同机固件发送与接收路径修复 channel 8/10/11 的累计确认处理；合成向量不含设备凭据。
- 后续无账号真机流程成功：AP 配网、仅目标设备 DNS 引导、HTTP/TCP 本地绑定及新密码取流。初始配网清除了 P2P 参数，实验显式采用固件共享 AP 引导参数恢复 LAN 监听；不是生成新的唯一云身份。
- 新凭据在 NAS 主机取得 119 视频帧 / 132 音频帧；实际解码 30 帧 JPEG。桥接 RTSP 检出 640×480 H.264 与 8 kHz 单声道 AAC，音视频连续解码 12 秒，另解码麦克风 4 秒。Frigate 恢复实际帧率，无需改变原 RTSP 访问凭据。
- 后续将 P2P TCP 地址改为本地目标，并修复 HLP 累计确认。RTSP 音视频及麦克风再次解码通过；重启前连续三分钟的 13 次采样均收到新音视频，Frigate 持续收帧，重连计数为 0。真实身份核对后的软件重启也恢复了取流，绑定密码、token 和首次下发时间不变；启动阶段仍发生一次自动重连和 Frigate 短暂零帧，随后恢复。尚未确认所有断流触发因素，不等同于断电冷启动或长期稳定性。

后续恢复修复新增验证：

- Linux 内核状态锁排除第二写入者，工作进程被 SIGKILL 后自动释放；原密码不会再次下发。NAS 绑定容器真实崩溃后自动重启并恢复 healthy，密码、token 和首次下发时间未变。
- 原先约 6–8 秒的控制重试截止会在媒体仍到达时断开；改为 30 秒绝对截止、逐步放缓重传并合并周期保活。短时实际 RTSP 解码通过，但约四分钟后仍出现完全无入包超时，不能认定全部稳定性问题已解决。
- 该次无入包与绑定服务五分钟固定断开时间相符；已移除认证连接的固定寿命，保留 90 秒空闲、未完成阶段的绝对期限和每窗口流量上限。离线测试覆盖跨窗口持续心跳、超限拒绝及空闲退出。
- Docker 与 HAOS 选项的仅本地模式均拒绝厂商登录 / 选择接口，已有配置保持不变。在 NAS 实例开启后，两个接口实际返回 403。强制结束媒体工作进程后 Docker 自动重启，并恢复新音视频；设备配置及管理密钥未变，启动阶段发生过一次自动重连。
- NAS 的 Docker 服务为 enabled / active，两个容器设置 `unless-stopped`。未重启承载其他业务的 NAS，不能把配置检查与进程恢复称为整机冷启动验证。
- 移除五分钟硬断开后，104 次、约九分钟采样均有新音视频、重连数不变；随后继续运行仍出现一次完全无入包及绑定重新登记。已确认的生命周期问题得到修正，但长期稳定性尚未通过。新增仅含固定原因枚举和时长的绑定断线诊断，用于区分本地主动超时与对端关闭。

当前 30 项测试（18 项绑定、2 项 Linux 锁、7 项控制确认/重试、3 项运行模式）在无网络的 Linux 临时容器中全部通过。Windows 沙箱因临时文件重命名权限拒绝而未能完成涉及原子存储的测试；这次部署验证以 Linux Docker 为准。

原始抓包、录像和认证比对数据含隐私，未随仓库提供。因此公众不能只凭本仓库独立复现这些历史真机结论。后续应补充不含私人信息的测试向量及更多型号验证。
