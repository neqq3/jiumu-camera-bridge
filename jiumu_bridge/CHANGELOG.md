# 0.1.0-dev.2

- HAOS 默认 RTSP 端口改为 19554，避开 Home Assistant 自带的 18554。旧安装需手动修改选项。
- 端口被占用时显示具体提示，并等待端口可用后重试，不再把其他 RTSP 服务误报为就绪。
- 保留设备凭据时，加载项重启后自动恢复音视频；已在 amd64 HAOS 真机验证。

# 0.1.0

- 独立实现九目账号登录和设备列表，无需从 APP 提取配置。
- 纯 Node.js 实现 HLP2P 局域网发现、认证、分片重组与保活。
- 输出带密码的 H.264 / AAC RTSP，包含麦克风音频。
- 网页设备选择、实时状态、自动重连和 Frigate 配置生成。
- 提供 Docker 和 HAOS Ingress 打包；HAOS 与 aarch64 待实机验证。
